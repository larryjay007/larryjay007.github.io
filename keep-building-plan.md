# The Plan to Keep Building

## How to Add the Next Case Study

**Where it goes:** a new section on `case-study.html`, right after "Check 2" and before the
closing note — following the exact same pattern as the two checks already there.

**The steps, every time:**
1. Open the Claude Project (already has my voice card, identity kit, and proof statement
   loaded — no rebuild needed).
2. Describe the real piece of work in three beats, same shape as every case so far:
   - **The problem** — what looked fine at first, in plain terms.
   - **What I did** — what I actually checked, questioned, or verified, and what I found.
   - **What came of it** — the honest takeaway, stated in safe/observed language, not
     oversold.
3. Ask Claude to draft it in-voice, then read it aloud once and cut anything that doesn't
   sound like me — same edit-hard step from Week 2.
4. Add it to `case-study.html` using the same `.finding` block markup already there
   (`flagged` / `verified` tag styling), export any real screenshot the same way the first
   two checks did (crop, remove watermarks, compress).
5. Update `CAPSTONE-INDEX.md` and the Home page's "Latest catch" teaser if this new case
   becomes the strongest one.
